Bash Commands I Have Learnt

1. touch

File creation
The touch command creates a new, empty file. If the file already exists, it updates the file’s last-modified timestamp instead of changing its content.

Syntax: touch filename

Example: touch notes.txt

Output: (no output — the file is created silently)

2. mkdir

Folder creation
The mkdir command creates a new, empty folder (directory) at the location you specify.

Syntax: mkdir foldername

Example: mkdir project

Output: (no output — the folder is created)

3. cd

Changing directory
The cd command changes the current working directory, moving you into a different folder.

Syntax: cd foldername

Example: cd project

Output: (prompt changes to show you are now inside ~/project)
